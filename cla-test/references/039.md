## 重编 simv_verdi（负结论前必做，见 SKILL.md 二进制新鲜度门禁）

039 **没有** `agent_compile.sh`，也**不需要** `PRJ` 变量（与 p65 不同）：直接 `cd ~/Desktop/039/vcs && make comp_verdi`
即可（用相对 `filelist_full.dat`，`setup=+define+CORE0+CLA0`，`-o simv_verdi`）。bgtask trace 的
`$fopen("cla_bgtask_sprs_trace.dat")` 在 tb 里**不受任何 `ifdef` 守护、始终编入**，故默认 `make comp_verdi`
产出的二进制就能生成 trace，无需额外宏。编完用**时间戳/大小**确认确实是新版（本 skill 实证：旧 6/14 版
2454456B → 重编后 2592560B，行为随之从"无覆盖"变为"N=0/1 覆盖"）。经 WSL 跑：
`ssh HOST bash -s <<'R' ... cd ~/Desktop/039/vcs; make comp_verdi > agent_comp.log 2>&1; echo $?; ls -la simv_verdi ... R`。

## 网络：经 WSL VPN

039 的 `.199` 在乾芯内网，需 WSL 内的 UniVPN（`qx-on` 启动，虚拟网卡 `cnem_vnic`，虚拟 IP 10.10.10.x）。
Windows 与 WSL 的 VPN 通常单会话——若 Windows 端 VPN 在连，`qx-on` 起不来；反之亦然。确认连通用 TCP 而非
ICMP（该路径 ICMP 被防火墙禁）：`timeout 6 bash -c 'echo > /dev/tcp/10.18.30.199/22'`。

**从 git-bash 调 WSL 会把 `/mnt/d` 路径改写成 Windows 路径**——用 **PowerShell** 调 `wsl`
（`wsl -u zhaotao -- bash /mnt/d/.../脚本.sh`），或把命令写进脚本用 `/mnt/d` 路径执行。

**`~/.ssh/config` 的 `Host 10.18.30.*` 通配规则**（给内网 git 服务器 .198 用：User git + ed25519 密钥 +
禁密码）会**误捕 `.199`**。连 `.199` 要在命令行覆盖：
`-o User=zhaotao -o ProxyCommand=none -o PubkeyAuthentication=no -o PasswordAuthentication=yes -o PreferredAuthentications=password -o NumberOfPasswordPrompts=1`。
`.199` 是 RHEL7，注意 pam_faillock/fail2ban——一次认证成功，别循环重试。

**凭据处理（标准习惯）**：不要把密码作为命令行参数（会进 shell 历史/进程列表/日志）。可用密钥认证，
或用 `sshpass -f <文件>` 从一个 600 权限文件读取——该文件可由 python 从 `config_039.json` 生成，
例如 `python3 -c "import json;print(json.load(open('.../config_039.json'))['ssh']['password'])" > ~/.qxpass039 && chmod 600 ~/.qxpass039`。

## 手动 WSL 上传/仿真/下载（推荐模式）

因为 039 网络在 WSL、而工具用 Windows paramiko，最稳的是：**用工具本地编译（`--no-remote-run`）拿镜像，
再用 WSL 手动上传/仿真/下载**。参考 `scripts/qx039.sh`（本 skill 自带的辅助脚本模板）：它封装了
`survey`（勘察远端）、`ssh <cmd>`、`scp_to`/`scp_from`、`runfile <本地脚本>`（把脚本喂给远端 bash）。
把它复制到 `cla_bg_039\agent\` 按需改 host/路径后用。

典型步骤：
1. 本地编译：`python run_039_bg.py --skip-generate --source custom_random\<f>.s --case <n> --no-remote-run --no-reference-sim`。
2. 上传 4 个 WO 镜像（改名到 `outer_*_mem_*.dat`，映射见 `config_039.json` 的 `uploads`）：
   `dram_image.core0.dat→outer_data_mem_core0.dat`、`iram_image.core0.dat→outer_insn_mem_core0.dat`、
   `dram_image.cla0.dat→outer_data_mem_cla0.dat`、`iram_image.cla0.dat→outer_insn_mem_cla0.dat`。
   scp 不能改名，可先原名上传再远端 `cp` 改名。
3. 远端（用 `ssh HOST bash -s <<'REMOTE' ... REMOTE`，避开 csh）：清旧 trace、写 run.do、
   `timeout 400 ./simv_verdi -ucli -do run.do`、报告 `cla_bgtask_sprs_trace.dat` 大小。
4. 下载 `cla_bgtask_sprs_trace.dat`，按 `trace-and-probe.md` 解析。

注意：`bootloader_uploads_enabled=false`（无需 bootloader 文件）；`dram_image.cla0.dat` 可能是 0 字节
（.cla.data 为空）属正常。BG task trace 可能在末尾截断，最后一组 `movc2g` 抓不到——在用例末尾多加
1~2 个 padding 组即可让真正的最后一组落入捕获窗口。
